# Speech model attribution

This image includes Moondream Parakeet Ultra, derived from NVIDIA
Parakeet TDT 0.6B v3, under Creative Commons Attribution 4.0 International.

- Model: https://huggingface.co/moondream/parakeet-ultra
- Upstream: https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3
- License: https://creativecommons.org/licenses/by/4.0/
- Revision: `73175eb7aeb0d82f1e2a6b53b3aabc10a90bcd0b`

Veoveo packages the published model without modifying its weights. Moondream
provides the fine-tuned checkpoint and Photon inference implementation.
