# Testing Support Agent Instructions

## Purpose

Maintain reusable test transport, declaration, compiler delivery and local ownership mechanics.

## Invariants

Keep production domain vocabulary and installed registries in owner or composition assertion source. Preserve typed identities, secret redaction and owner reconciliation after unknown remote outcomes. A successful process exit cannot qualify a missing or skipped framework case.

## Build And Test

Run owning Rust tests and the independent descriptor/framework cases through the coordinated repository qualification matrix. Cargo metadata and native staging checks need the actual selected target graph. Hardware/provider acceptance remains with its owner.

## Contract Compliance

This component is test infrastructure, not a hosted MCP server. Its maintained protocol clients consume the shared contract; its descriptor and artifact formats are owned here.
