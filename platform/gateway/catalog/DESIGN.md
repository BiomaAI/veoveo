# Gateway Catalog Composition

## Standards And Protocols

| Boundary | Supported profile |
|---|---|
| Gateway catalog JSON | Existing kernel and owner action spellings, tagged policy targets and flattened owner sections; admission rejects undeclared sections and actions |
| Rust extension interfaces | Registry-bound owner vocabulary keys and immutable section/target codecs from `veoveo-gateway-contract` and `veoveo-types` |

## Registration And Consumers

This library assembles the installation's catalog declarations once. Gateway
composition, standalone service binaries, installation validation and schema
producers use the same recipe. Each process constructs the registry before reading a
catalog and passes clones into its readers and publishers. Reload preserves that
binding; an action handle or target from another registry fails admission.

The package depends on owner contract features. It starts no workers and contains no
HTTP, database or MCP implementation. A separate package lets several binaries share
the recipe without importing the gateway executable's runtime dependencies. Owner
runtime libraries receive the registry and do not import this composition.

Schemas are generated by the consuming protocol adapter from this registry. They
include only bound action choices and declared target kinds and sections. Owner
configuration and policy semantics stay in their contract and policy adapter.
