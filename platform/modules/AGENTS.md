# Module Foundation

Keep the default declaration library dependency-free. Domain claims belong to owners;
the registry enforces generic ownership and dependency rules.

The runner's parser/AST pins move together. Every admitted syntax variant needs complete
child inspection and adversarial tests; unrecognized variants fail before any database
effect. Execute only through an immutable prepared installation. Preserve explicit
transaction cancellation, history identity and known disabled-module histories.

Use the existing isolated database fixture for native runner checks. Production bootstrap
and deployment Jobs require their own qualification before changing installation behavior.
